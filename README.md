# Naive Bayes Text Classifier

Implementation of a Naive Bayes text classifier from scratch for SMS Spam Collection and BBC News classification.

## Project Components

- Text preprocessing and tokenization
- Vocabulary construction
- Prior probability estimation
- Multinomial and binary likelihood estimation
- Laplace smoothing
- Log-probability based prediction
- Accuracy evaluation
- Confusion matrix
- Indicative-word analysis
- Example test cases
